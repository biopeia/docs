# Decision Notes

Decision Notes (DNs) record material, local, reversible decisions that are too
consequential for an Issue comment but do not warrant an ADR. They do not
change domain-owned contracts or protected invariants. Number records
sequentially as `DN-0001`, `DN-0002`, and so on. Preserve superseded notes as
history and link the replacement.

Use the [DN template](../templates/procedure/decision-note.md). The record is
the authority for the decision itself; document frontmatter carries identity
metadata only.
