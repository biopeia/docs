## Decision

TARGET ecosystem/project identity is **Biopeia**; Canonical GitHub organization: `github.com/biopeia`. The individual formerly referred to as Symbiont is **Organism**. “Symbiont” is not a target project or individual-entity name. Naming does not imply repository topology, a master repository, workspace/integration repository, or extraction; those remain governed by AD-0001 and Pass 15 falsification. Existing pinned/current uses of `symbiont` remain evidence and are not renamed during this audit.

## Ratification and evidence

Ratification authority: Architecture Owner. EV-0271. No current GitHub resource existence or code compliance is implied; migration/documentation implementation is out of scope. UC-0001 removes any backward-compatibility obligation for the former name; AD-0002/OP-0002 separately govern scientific/historical meaning and assets.
